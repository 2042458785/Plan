# Polymarket 双腿 Taker 模拟器

在项目根目录的终端运行：

```bash
cd polymarket_project
go run .
```

第一屏选择 **简体中文 / English**，默认高亮简体中文，按 **Enter** 确认。在设置页按 **Tab** 切换字段，按 **左右方向键**选择模式和方向，按 **Enter** 启动，按 **Esc** 可返回语言选择。模式下方会显示用途。

| 模式 | 用途 |
| --- | --- |
| 演示成交 | 用固定样例盘口练习双腿成交，适合第一次使用 |
| 演示单腿超时 | 故意让 B 腿超时，查看 500ms 风控如何平掉 A 腿 |
| 真实盘口观察 | 输入两个市场和方向，只看实时盘口和时间差 |
| 真实盘口模拟 | 用真实盘口和虚拟资金模拟成交，需核对结算规则并填写每对最低兑付 |

演示模式默认每腿 5 份，虚拟本金 $10,000。把「虚拟本金」填成 `5` 或 `50` 就能试对应账本。

在两个真实盘口模式中，先把光标移到「市场 A 标识」或「市场 B 标识」，按 **Ctrl+F** 搜索。可输入关键词（例如 `Bitcoin above`），也可粘贴 Polymarket 事件链接。搜索只列出当前模拟器支持的「是 / 否」盘口。按 **Enter** 搜索，再选事件和具体盘口，按 **Enter** 填回对应的腿。

运行后，顶部一行显示策略状态、连接、双腿时间差和行情往返延迟。宽终端同屏显示搜索、市场列表和买卖盘口，下方显示关键动作日志和模拟账户。真实盘口模式在市场面板显示 A/B 两腿最近一笔公开成交。

**Ctrl+F** 搜索，选中市场后按 **Enter** 打开只读盘口预览。**O** 切换预览的是/否方向，**A / B** 返回策略盘口。**Tab** 切换盘口与日志焦点，**上/下键**滚动。**P** 暂停新信号，**R** 重连，**Q** 退出。虚拟账本随进程退出清空。

「行情往返」是当前 Polymarket 行情 WebSocket 的 Ping/Pong 往返耗时，约每 10 秒测一次。「时间差」是 A、B 两腿的交易所盘口更新时间差。演示模式和暂未测得延迟时显示 `--`。

## 环境

当前项目目录已准备 Python 环境。首次检出需要 Go 1.26.2 和 Python 3.12。在项目根目录执行：

```bash
python3.12 -m venv python_adapter/.venv
python_adapter/.venv/bin/python -m pip install -r python_adapter/requirements.lock
```
