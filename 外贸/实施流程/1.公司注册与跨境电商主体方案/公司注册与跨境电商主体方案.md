# 公司注册与跨境电商主体方案

> 适用对象：准备做跨境电商、1688 一件代发、AI Agent / 软件开发的新手创业者。  
> 当前状态：公司未注册，平台未注册，业务方向已明确。  
> 核心目标：先注册一个能覆盖“跨境电商 + 软件开发 + AI Agent”的低风险主体。

---

## 1. 最终结论

你最适合先注册：

```text
[地区] + [字号] + 科技 + 有限公司
```

推荐配置：

| 项目 | 建议 |
|---|---|
| 公司类型 | 有限责任公司（自然人独资） |
| 行业表述 | 科技 |
| 注册资本 | 10 万-30 万元优先，不建议一开始写太高 |
| 出资方式 | 货币出资 |
| 出资期限 | 按新公司法要求，一般应在公司成立后 5 年内缴足 |
| 股东 | 你自己 100% 持股 |
| 法定代表人 | 你自己 |
| 执行董事 / 经理 | 你自己 |
| 监事 | 按当地登记系统要求处理；如要求填写，可找可信任家人担任 |
| 主营方向 | 软件开发、AI Agent 技术服务 |
| 兼营方向 | 跨境电商、互联网销售、货物进出口 |
| 初始纳税身份 | 小规模纳税人 |
| 记账报税 | 必须做；没有收入也要零申报 |

一句话：

> 公司名字用“科技”承接软件和 AI，经营范围覆盖跨境电商，注册资本不要虚高，税务上按真实业务分别核算。

## 2. 你为什么需要公司

你做跨境电商和 AI Agent，个人身份能做一部分事情，但公司主体更稳。

公司主要解决 6 个问题：

1. 平台入驻需要营业执照。
2. 跨境收款账户通常需要企业资料。
3. 货代、供应商、平台沟通更正规。
4. 后续做 Amazon / TikTok Shop / eBay 企业店更方便。
5. 软件开发、AI Agent 服务可以签合同、开发票。
6. 公司能把个人资产和经营风险做一定隔离。

但注意：

> 公司不是护身符。公司钱和个人钱混用、虚假出资、逃税、侵权、卖违规产品，仍然可能追到个人责任。

## 3. 公司名称怎么选

公司名称通常由四部分组成：

```text
行政区划 + 字号 + 行业 + 组织形式
```

例如：

```text
雅安市 + XX + 科技 + 有限公司
成都 + XX + 科技 + 有限公司
四川 + XX + 科技 + 有限公司
```

### 3.1 行业选“科技”还是“电子商务”

推荐：**科技**。

原因：

- 你不只是卖货，还要做 AI Agent、软件开发、自动化系统。
- “科技”覆盖软件、AI、技术服务、电商工具开发。
- “电子商务”更像单纯卖货，未来做软件外包、SaaS、Agent 服务时不够宽。
- “电子科技”容易让人以为你做硬件、电子元器件，不如“科技”通用。

### 3.2 推荐名称结构

优先：

```text
[地区] + [字号] + 科技有限公司
```

备选：

```text
[地区] + [字号] + 网络科技有限公司
[地区] + [字号] + 信息科技有限公司
[地区] + [字号] + 电子商务有限公司
```

我的排序：

1. 科技有限公司
2. 网络科技有限公司
3. 信息科技有限公司
4. 电子商务有限公司

### 3.3 字号怎么选

字号就是公司名字里真正属于你的部分。

要求：

- 2-4 个字更好记。
- 不要用知名品牌近似词。
- 不要用行业禁用、夸大、国家级词汇。
- 尽量能同时适配电商和软件业务。

示例结构：

```text
XX科技有限公司
XX网络科技有限公司
XX信息科技有限公司
```

## 4. 公司类型怎么选

你现在最适合：

```text
有限责任公司（自然人独资）
```

### 4.1 为什么不是个体工商户

个体工商户便宜、简单，但不适合你的长期目标：

- 平台企业店入驻不如公司主体稳定。
- 软件开发、AI Agent 服务签约不够正规。
- 股权、融资、合作、品牌化空间小。
- 经营风险和个人绑定更强。

### 4.2 为什么不是合伙企业

合伙企业适合多人共同创业，但你现在没有稳定合伙人，不建议上来就做。

合伙企业的风险：

- 责任边界更复杂。
- 分账、退出、决策容易扯皮。
- 不适合你现在快速试错。

### 4.3 为什么不是两人公司

如果只是为了找人当“形式股东”，不建议。

原因：

- 股东有股权就是权利。
- 后续分红、退出、转让、控制权都可能产生问题。
- 亲友挂股容易留下长期隐患。

所以，你现在建议：

```text
你自己 100% 持股。
```

## 5. 法人、法定代表人、股东、监事是什么

### 5.1 法人

严格说，**公司本身才是法人**。

你平时说“我是法人”，通常实际意思是：

```text
我是公司的法定代表人
```

公司作为法人，可以：

- 签合同。
- 开银行账户。
- 开票。
- 持有资产。
- 承担债务。
- 起诉和被起诉。

### 5.2 法定代表人

法定代表人是公司对外的代表。

他的作用：

- 代表公司签字。
- 代表公司办理平台、银行、税务事项。
- 在很多文件上承担最终责任。

你当前适合自己担任法定代表人。

风险：

- 公司违法经营，法定代表人可能被限制高消费、限制出境、被列入异常。
- 税务、工商、平台违规，法定代表人往往是第一责任联系人。

### 5.3 股东

股东是公司的出资人和所有者。

你 100% 持股，意味着：

- 公司利润归你。
- 公司重大事项你决定。
- 注册资本出资义务由你承担。
- 公司经营风险最终也主要与你相关。

### 5.4 执行董事 / 经理

小公司通常不设董事会，只设执行董事。

执行董事偏决策，经理偏日常经营。

你当前可以自己担任：

```text
法定代表人 + 执行董事 + 经理 + 100% 股东
```

### 5.5 监事

监事是监督公司财务和管理行为的人。

新公司法下，小规模公司组织结构更灵活。实务中，不同地区登记系统处理方式可能不同：

- 有的仍要求填写监事。
- 有的允许小公司简化治理结构。

实操建议：

```text
先准备一位可信任家人作为监事候选。
如果当地登记系统允许不设监事，再按系统简化。
```

监事不能随便找不熟的人。

## 6. 注册资本怎么写

推荐：

```text
10 万-30 万元
```

不建议：

```text
100 万、500 万、1000 万
```

### 6.1 注册资本是什么

注册资本不是你现在必须马上拿出来的钱。

它是你对公司承诺的出资额。

新公司法下，有限责任公司股东认缴出资一般应在公司成立后 5 年内缴足。

所以注册资本不能乱写。

### 6.2 为什么不建议写太高

因为注册资本越高，你未来出资义务越高。

例如：

```text
注册资本 100 万
你 100% 持股
你未来需要按章程约定承担 100 万出资义务
```

如果未来公司债务、纠纷、清算，注册资本写太高会增加压力。

### 6.3 为什么不建议写太低

注册资本太低也不好。

比如：

```text
1 万元
```

可能带来问题：

- 平台或合作方觉得公司太弱。
- 后续申请部分资质、贷款、合作时不够体面。
- 做软件服务或跨境业务显得不专业。

### 6.4 你的合理选择

如果保守：

```text
10 万元
```

如果想兼顾形象：

```text
30 万元
```

如果未来可能接软件项目、AI Agent 服务：

```text
50 万元也可以，但不建议超过 50 万
```

我的建议：

> 第一家公司写 10 万或 30 万即可。

### 6.5 注册资本以后能改吗

可以。

增资相对简单。  
减资更麻烦。

减资通常涉及：

1. 股东决定。
2. 修改章程。
3. 通知债权人。
4. 公告。
5. 债务清偿或担保说明。
6. 变更登记。

所以一开始不要写太高。

## 7. 股权怎么设计

你现在建议：

```text
你 100%
```

原因：

- 决策最快。
- 没有合伙人纠纷。
- 不用分红。
- 不用处理退出。
- 适合从 0 到 1 试错。

### 7.1 不建议随便给别人股份

不要因为以下原因给股份：

- 找人帮忙注册。
- 找朋友做监事。
- 对方说以后帮你卖货。
- 对方只是提供建议。

股份一旦给出去，后续收回很麻烦。

### 7.2 未来需要合伙人怎么办

等业务验证后再处理。

可以用：

- 劳务合作。
- 项目分成。
- 顾问费。
- 期权协议。
- 股权转让。

不要一开始就把股权分出去。

## 8. 经营范围怎么写

经营范围要解决 3 件事：

1. 覆盖跨境电商。
2. 覆盖软件开发和 AI Agent。
3. 避免写入暂时不做的高监管业务。

### 8.1 经营范围不是随便手写

现在登记系统通常使用规范化表述。

也就是说，你不是自由作文，而是在系统里选择标准条目。

如果找不到完全一样的词，用关键词搜索相近条目。

### 8.2 推荐经营范围草案

建议优先使用以下结构：

```text
一般项目：
软件开发；
人工智能应用软件开发；
人工智能基础软件开发；
技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广；
信息技术咨询服务；
信息系统集成服务；
数据处理服务；
互联网销售（除销售需要许可的商品）；
日用百货销售；
化妆品零售；
家居用品销售；
办公用品销售；
文具用品零售；
箱包销售；
针纺织品销售；
服装服饰零售；
鞋帽零售；
美发饰品销售；
个人卫生用品销售；
厨具卫具及日用杂品零售；
电子产品销售；
国内贸易代理；
供应链管理服务；
货物进出口；
技术进出口；
进出口代理；
广告设计、代理；
市场营销策划；
摄像及视频制作服务。
```

最后通常会带：

```text
除依法须经批准的项目外，凭营业执照依法自主开展经营活动
```

### 8.3 可选但谨慎写的范围

这些不是不能写，但要看你是否真的做：

| 范围 | 是否建议现在写 | 原因 |
|---|---|---|
| 化妆品零售 | 暂不优先 | 你目前不建议主做彩妆，写了也不代表能绕开平台和合规 |
| 宠物食品及用品零售 | 谨慎 | 如果只卖宠物工具，可以后续再看，别碰宠物食品 |
| 食品销售 | 不建议 | 许可和监管复杂 |
| 医疗器械销售 | 不建议 | 资质要求高 |
| 第二类增值电信业务 | 不建议现在写 | 需要许可，不是普通软件开发 |
| 互联网信息服务 | 暂不建议 | 可能涉及 ICP 许可 |

### 8.4 为什么要写“货物进出口”

你做跨境电商，未来可能需要：

- 出口货物。
- 做海关备案。
- 和货代、平台、收款机构解释业务。
- 申请跨境电商相关政策。

所以建议写：

```text
货物进出口
技术进出口
进出口代理
```

### 8.5 为什么要写“软件开发”和“人工智能应用软件开发”

你未来可能做：

- AI Agent 自动化系统。
- 选品工具。
- 订单处理工具。
- SaaS 服务。
- 软件外包。
- 技术咨询。

这些需要技术类经营范围承接。

## 9. 经营范围能不能改

可以改。

公司成立后，经营范围可以变更。

常见流程：

1. 股东决定。
2. 修改章程或章程修正案。
3. 在政务服务网提交变更。
4. 市场监管部门审核。
5. 换发营业执照或更新登记信息。

所以不要为了“以后可能做任何事”把经营范围写得过度复杂。

原则：

> 第一版覆盖未来 6-12 个月会做的业务即可。

## 10. 怎么写经营范围能降低税

关键结论：

> 经营范围本身不能直接降低税。税负取决于真实业务、发票、收入性质、纳税人身份、核算方式和适用政策。

不要以为：

```text
把软件开发写在前面 = 所有收入都按低税率
```

这是错误理解。

### 10.1 正确税务逻辑

如果你卖实物商品：

```text
收入性质 = 商品销售
```

如果你做软件开发：

```text
收入性质 = 技术服务 / 软件服务
```

不同业务要分别核算。

### 10.2 小规模纳税人和一般纳税人

你初期建议小规模纳税人。

原因：

- 起步销售额低。
- 账务简单。
- 小规模阶段通常更适合轻资产试错。
- 达到规定销售额后再转一般纳税人。

一般逻辑：

```text
年应税销售额超过 500 万元，通常会涉及一般纳税人认定。
```

### 10.3 商品销售和技术服务要分开核算

建议账务上分清：

```text
跨境电商商品销售收入
软件开发收入
技术服务收入
广告/内容服务收入
```

不要混在一起。

如果混在一起，后续税务解释会困难。

### 10.4 软件企业优惠不是写了就有

经营范围里写“软件开发”，只是基础。

真正享受软件企业、研发费用等优惠，需要满足实际条件，例如：

- 真实研发活动。
- 研发人员。
- 研发费用归集。
- 软件著作权或相关成果。
- 财务核算清楚。
- 符合当年政策要求。

所以：

> 不要为了税收优惠虚构软件开发业务。

### 10.5 跨境电商无票免税不是自动适用

“跨境电商无票免税”不是只要你卖海外就自动享受。

通常需要满足特定条件，例如：

- 属于跨境电商综合试验区相关业务。
- 通过规定的跨境电商出口模式申报。
- 有平台交易数据、物流数据、支付数据。
- 有合规的出口申报链路。
- 符合税务机关要求。

你从 1688 买货，让货代发海外，不等于自动免税。

实操建议：

> 前期先按普通小规模企业规范记账，不要一开始就假设自己能享受所有跨境税收优惠。

### 10.6 合法降低税负的方式

你能做的是：

1. 初期选择小规模纳税人。
2. 所有成本尽量取得合规凭证。
3. 商品销售和技术服务分别核算。
4. 不做无法解释资金流的交易。
5. 软件开发真实发生时，规范归集研发费用。
6. 业务做大后，让会计评估跨境电商综试区政策、出口免税、所得税核定等。

不能做：

- 虚开发票。
- 私账收款。
- 故意隐瞒收入。
- 把商品销售伪装成技术服务。
- 用经营范围包装虚假业务。

## 11. 注册地址怎么选

你需要一个可用于工商登记的地址。

选择顺序：

1. 自有或真实办公地址。
2. 合规园区地址。
3. 合规商务秘书 / 挂靠地址。

不要使用来路不明的低价地址。

风险：

- 地址异常。
- 收不到工商、税务、法院、平台信件。
- 银行开户被拒。
- 平台审核失败。

最低要求：

```text
能接收工商税务信件
能配合核验
能提供地址证明
不是异常地址
```

## 12. 注册公司后必须做什么

公司注册完成后，不是结束。

你还要做：

1. 领取营业执照。
2. 刻章。
3. 银行开户。
4. 税务信息确认。
5. 电子税务局登录。
6. 选择财务制度。
7. 找代理记账。
8. 每月或每季度申报。
9. 没收入也零申报。
10. 每年工商年报。

### 12.1 印章

通常包括：

- 公章。
- 财务章。
- 法人章。
- 发票章。
- 合同章。

小公司起步至少要管理好公章、财务章、法人章。

### 12.2 银行账户

建议开对公账户。

原因：

- 平台收款更规范。
- 供应商付款更清楚。
- 税务账务更容易解释。
- 公司和个人资金分离。

### 12.3 代理记账

建议找代理记账。

但你自己也要懂基本逻辑：

```text
收入要入账
成本要留凭证
平台费用要记录
货代费用要记录
供应商采购要记录
```

## 18. 你应该避免的 10 个错误

1. 注册资本写太高。
2. 找不可信的人当股东。

7. 不买样品直接上架。
8. 用 1688 原图直接铺货。
9. 货代时效没确认就承诺客户。
