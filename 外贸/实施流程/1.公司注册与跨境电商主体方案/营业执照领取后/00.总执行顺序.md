# 营业执照领取后的总执行顺序

> 当前状态：营业执照已经领取。
> 当前目标：搭好域名、邮箱、银行、跨境收款和 eBay 账户链路。
> 执行原则：所有平台使用真实一致的公司资料；先完成基础设施，再上架商品。
> 政策核对日期：2026-07-17。

## 1. 总流程

```text
确认印章和税务
-> 注册公司域名
-> 创建公司邮箱
-> 开立对公基本存款账户
-> 注册万里汇跨境电商公司账号
-> 尝试注册 eBay 企业卖家账号
-> 确认英国物流
-> 购买样品
-> 计算真实成本
-> 上架第一批商品
```

域名和银行预约可以同时开始，但平台账户不要在资料混乱时仓促注册。

## 2. 五项工作的依赖关系

| 项目 | 前置条件 | 完成标志 |
|---|---|---|
| 公司域名 | 营业执照、阿里云账号、企业实名信息模板 | `.com` 域名归公司控制，自动续费和安全设置完成 |
| 公司邮箱 | 公司域名、DNS 管理权限 | 企业邮箱能稳定向外部邮箱收发邮件 |
| 对公账户 | 营业执照、印章、法人身份证、真实经营信息 | 基本存款账户开通，网银和电子回单可用 |
| 万里汇 | 企业邮箱、公司和法人资料 | 公司实名认证通过，同名提款账户绑定完成 |
| eBay | 企业邮箱、公司资料、手机号、平台要求的收款方式 | 企业卖家认证通过或得到明确拒绝原因 |

## 3. 邮箱和账号分工

建议创建：

```text
admin@你的域名.com
marketplace@你的域名.com
finance@你的域名.com
support@你的域名.com
```

用途：

| 邮箱 | 用途 |
|---|---|
| `admin@` | 企业邮箱管理员，只用于后台和安全恢复 |
| `marketplace@` | eBay、Amazon 等电商平台 |
| `finance@` | 万里汇、银行、支付和财务服务 |
| `support@` | 买家客服、供应商和售后 |

不要使用 `admin@` 注册公开平台，也不要让代运营掌握域名和邮箱超级管理员权限。

## 4. 公司资料必须统一

以下字段在银行、万里汇、eBay和其他平台中必须以营业执照和身份证为准：

1. 公司中文全称。
2. 统一社会信用代码。
3. 注册地址。
4. 法定代表人姓名和证件号码。
5. 股东和持股比例。
6. 联系电话。
7. 经营地址。

公司英文名称和英文地址没有官方登记版本时，应建立一份固定翻译稿，所有平台保持相同拼写，不要每次临时翻译。

## 5. 推荐的 30 天节奏

### 第 1 周

1. 确认印章、税务和代理记账。
2. 注册 `.com` 域名。
3. 开通企业邮箱。
4. 预约银行开户。

### 第 2 周

1. 完成银行尽职调查和基本户开户。
2. 注册万里汇跨境电商公司账号。
3. 联系英国专线货代。

### 第 3 周

1. 尝试 eBay 企业卖家自助注册。
2. 购买 6 个样品。
3. 整理供应商供货和无痕发货资料。

### 第 4 周

1. 完成样品评分和物流称重。
2. 计算真实总成本。
3. eBay 通过后准备英国站 4-6 个 SKU。
4. eBay 未通过时，保留审核记录并继续完成供应链和内容准备。

## 6. 当前不要做的事情

1. 不同时注册多个 eBay 账号。
2. 不购买老账号、老营业执照或海外身份。
3. 不用虚假英国地址注册。
4. 不把个人银行卡当成长期公司经营账户。
5. 不在没有样品和物流报价时上架。
6. 不将域名、邮箱管理员和银行 U 盾交给代运营保管。
7. 不假设万里汇一定能替代 eBay 页面指定的 Payoneer 或银行收款方式。
