# 公司域名注册

> 推荐方案：在阿里云使用公司主体注册一个长期持有的 `.com` 域名。
> 域名用途：企业邮箱、公司网站、品牌识别、平台联系和后续独立站。
> 政策核对日期：2026-07-17。

## 1. 域名是什么

域名是公司的互联网地址，例如：

```text
exampleglobal.com
```

购买域名不等于创建网站，也不等于自动拥有企业邮箱。域名注册完成后，你获得的是这个名称的管理权和 DNS 解析权。

后续可以把域名用于：

```text
www.exampleglobal.com
marketplace@exampleglobal.com
finance@exampleglobal.com
support@exampleglobal.com
```

## 2. 域名选择标准

优先满足：

1. 使用 `.com`。
2. 6-12 个英文字母更容易记忆。
3. 不使用数字和连字符。
4. 读音清楚，不容易拼错。
5. 不绑定假睫毛、衣架等单一产品。
6. 能同时覆盖跨境电商、软件和 AI 业务。
7. 不包含 Amazon、eBay、TikTok 等第三方商标。
8. 搜索是否存在同名公司、商标和高相似度品牌。

不要因为某个域名便宜就立即购买。域名一旦绑定企业邮箱、收款和平台账户，后期更换成本很高。

## 3. 注册前准备

需要准备：

- 阿里云账号。
- 营业执照彩色扫描件。
- 统一社会信用代码。
- 公司完整名称。
- 法定代表人或域名联系人资料。
- 独立的个人恢复邮箱。
- 长期使用的手机号。
- 3-5 个候选域名。

域名正式注册前，阿里云要求使用通过实名认证的信息模板。信息模板主体就是域名持有者，建议选择公司，而不是随意登记在代办或员工个人名下。

## 4. 阿里云操作步骤

### 第一步：完成阿里云账号实名认证

登录阿里云后，在账号中心确认实名认证状态。建议使用公司主体实名认证；如果当前账号是个人实名，应确认能否建立企业域名信息模板并由公司作为域名持有者。

### 第二步：创建企业信息模板

进入：

```text
阿里云控制台
-> 域名
-> 信息模板
-> 创建信息模板
```

填写：

1. 域名持有者类型：企业或组织。
2. 公司名称：与营业执照完全一致。
3. 统一社会信用代码。
4. 所在地区和通信地址。
5. 联系人、手机号和邮箱。
6. 上传营业执照。

提交后等待模板实名认证通过。阿里云说明通常约 1 个工作日，部分情况可能需要 3-5 个工作日。

### 第三步：查询候选域名

在域名注册页面逐个查询候选 `.com` 域名：

- 是否可以注册。
- 首年和续费价格。
- 是否为溢价域名。
- 是否存在相似品牌或商标。

不要只看首年促销价，还要看正常续费价格。

### 第四步：购买域名

购买时：

1. 选择已经通过实名认证的企业信息模板。
2. 核对域名拼写。
3. 核对域名持有者是公司。
4. 建议购买 2-3 年或至少开启自动续费。
5. 使用自己控制的阿里云账号付款。

付款后在域名列表检查域名状态。只有完成实名认证且没有 `serverHold` 等锁定状态，域名才能正常解析。

## 5. 安全设置

域名注册完成后立即处理：

1. 阿里云账号开启双重验证。
2. 设置强密码。
3. 保存账号恢复码。
4. 开启域名到期提醒和自动续费。
5. 保留独立于公司域名的个人恢复邮箱。
6. 不把域名转移码发给代运营、供应商或不可信人员。
7. 不随意修改 DNS 服务器。

独立个人恢复邮箱必须保留。因为一旦域名过期或 DNS 配置错误，域名邮箱可能无法收信，此时仍需要独立邮箱恢复阿里云账号。

## 6. 完成验收

域名完成标准：

- [ ] 域名拼写确认无误。
- [ ] 域名持有者为公司。
- [ ] 信息模板实名认证通过。
- [ ] 域名状态正常。
- [ ] 阿里云账号开启双重验证。
- [ ] 自动续费或到期提醒已设置。
- [ ] 域名没有交给代办账号持有。
- [ ] 已记录购买日期、续费日期和管理账号。
