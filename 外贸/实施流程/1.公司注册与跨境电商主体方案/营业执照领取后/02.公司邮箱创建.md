# 公司邮箱创建

> 推荐方案：公司域名注册完成后，先使用阿里邮箱搭建自定义域名企业邮箱。
> 核心原理：DNS 中的 MX 记录指向哪家邮箱服务商，就由哪家服务商负责接收新邮件。
> 政策核对日期：2026-07-17。

## 1. 最终邮箱结构

建议创建：

```text
admin@你的域名.com
marketplace@你的域名.com
finance@你的域名.com
support@你的域名.com
```

用途：

| 邮箱 | 主要用途 |
|---|---|
| `admin@` | 企业邮箱超级管理员、安全恢复 |
| `marketplace@` | eBay、Amazon 等平台账号 |
| `finance@` | 万里汇、银行、支付和财务服务 |
| `support@` | 买家客服、货代、供应商和售后 |

## 2. 邮件系统如何工作

以 `marketplace@example.com` 为例：

```text
eBay 发出邮件
-> 查询 example.com 的 MX 记录
-> MX 指向阿里邮箱
-> 邮件送到阿里邮箱服务器
-> 阿里邮箱放入 marketplace@example.com
```

DNS 记录分工：

| 记录 | 作用 |
|---|---|
| MX | 决定由谁接收邮件 |
| SPF | 声明哪些服务器可以代表域名发邮件 |
| DKIM | 给发出邮件添加数字签名 |
| DMARC | 规定伪造邮件如何处理和汇报 |
| CNAME | 配置网页登录、客户端等别名地址 |

## 3. 为什么当前推荐阿里邮箱

- 域名和邮箱都在阿里云时可以快速添加解析。
- 中国大陆访问稳定。
- 适合及时接收 eBay、万里汇和银行验证码。
- 免费版已经足够一人公司起步。

阿里邮箱官方当前说明，免费版支持最多 50 个账号，每个邮箱 5GB。具体额度和资格以开通页面实时显示为准。

Google Workspace 也可以绑定阿里云域名，但在中国大陆作为唯一关键邮箱可能面临访问不稳定的问题。后期可以迁移邮箱服务商，域名所有权不会因此改变。

## 4. 开通步骤

### 第一步：申请阿里邮箱

进入阿里云：

```text
阿里邮箱
-> 选择免费版或付费版
-> 绑定公司域名
-> 设置管理员
```

如果申请免费版，注意阿里云页面提示的申请限制和完成解析期限。

### 第二步：配置 DNS

域名和邮箱在同一个阿里云账号时，优先使用：

```text
设置解析
-> 一键添加邮箱解析
```

系统通常会自动添加 MX 和 SPF 等记录。之后进入域名 DNS 控制台确认记录实际存在。

阿里邮箱常见 MX 记录示例：

```text
@  MX  5   mx1.qiye.aliyun.com
@  MX  10  mx2.qiye.aliyun.com
@  MX  15  mx3.qiye.aliyun.com
```

具体记录必须以当前阿里邮箱后台生成的内容为准，不要只照抄示例。

### 第三步：设置 SPF、DKIM 和 DMARC

1. SPF 通常使用 TXT 记录。
2. DKIM 从阿里邮箱管理后台获取专属记录值。
3. DMARC 建议先使用观察模式，再根据邮件情况提高策略。

注意：

- 同一根域名不要保留多条互相冲突的 SPF 记录。
- 不要同时保留阿里邮箱和 Google Workspace 两套 MX。
- 不要删除不理解的 DNS 记录，修改前先截图或导出。

### 第四步：创建邮箱账号

进入阿里邮箱管理员后台，创建：

1. `admin@`。
2. `marketplace@`。
3. `finance@`。
4. `support@`。

`admin@` 不用于注册平台，只负责管理员操作。平台账号与财务账号分开，可以降低一个邮箱泄露后全部账户同时失控的风险。

### 第五步：安全设置

1. 管理员和各邮箱使用不同强密码。
2. 开启双重验证。
3. 绑定长期使用的手机号。
4. 设置独立个人邮箱作为恢复方式。
5. 保存恢复码。
6. 不把邮箱密码通过微信明文发送给第三方。

## 5. 收发测试

正式注册 eBay 和万里汇前，完成以下测试：

1. 企业邮箱发送到 Outlook。
2. 企业邮箱发送到 Gmail。
3. 企业邮箱发送到 QQ 邮箱。
4. 三个外部邮箱分别回复。
5. 检查是否进入垃圾箱。
6. 检查发件人名称。
7. 检查 SPF、DKIM 是否通过。
8. 连续观察至少 24 小时。

如果收不到邮件：

1. 检查 MX 是否已经生效。
2. 检查域名是否处于正常状态。
3. 检查垃圾箱和反垃圾设置。
4. 检查是否配置了其他邮箱服务商的 MX。
5. 使用阿里云 DNS 检测工具检查记录。

## 6. 平台使用规则

- eBay 使用 `marketplace@你的域名.com`。
- 万里汇使用 `finance@你的域名.com`。
- 客服使用 `support@你的域名.com`。
- 域名和邮箱后台使用 `admin@你的域名.com`。

公司邮箱不是 eBay 的绝对硬性条件，但在公司已经成立的情况下，企业邮箱更适合长期管理和安全审计。

## 7. 完成验收

- [ ] MX 指向当前邮箱服务商。
- [ ] SPF 只有一条有效策略。
- [ ] DKIM 已启用。
- [ ] DMARC 已配置。
- [ ] 四类邮箱已经创建。
- [ ] 双重验证已经开启。
- [ ] 外部收发测试成功。
- [ ] 邮件没有普遍进入垃圾箱。
- [ ] 管理员和平台邮箱没有共用密码。
