# 万里汇企业账户注册

> 当前用途：为跨境电商平台准备企业收款、换汇和提款能力。
> 推荐账户类型：跨境电商公司账号。
> 不要误选：个人电商账号、外贸 B2B 账号或海外主体账号。
> 政策核对日期：2026-07-17。

## 1. 万里汇在资金链路中的位置

典型链路：

```text
海外电商平台销售款
-> 万里汇提供的平台收款账户
-> 万里汇余额
-> 换汇
-> 提款到公司同名对公账户
-> 会计入账
```

万里汇不是电商平台，也不是公司基本户。它是跨境收款和资金管理工具。

## 2. 注册前准备

- 营业执照。
- 法定代表人身份证。
- 持股超过 25% 的股东身份信息。
- 公司中文名称。
- 固定的公司英文名称和英文地址。
- 注册地址和实际经营地址。
- `finance@你的域名.com`。
- 法人长期使用的手机号。
- 公司主营业务、销售平台和目标国家说明。
- 对公账户资料；如果尚未开户，可以先认证，后续再绑定提款账户。

英文名称和地址应保存成固定版本，后续 eBay、万里汇和其他平台尽量使用同一套拼写。

## 3. 选择正确入口

在万里汇官方注册页选择：

```text
跨境电商
-> 注册跨境电商账号
```

不要选择：

- 外贸 B2B：用于传统外贸货物贸易收款，不是当前平台电商主账号。
- 海外主体：用于海外公司。
- 个人账号：你已经有公司，不建议再用个人主体搭建主资金链路。

## 4. 注册步骤

### 第一步：创建账号

可以使用手机或邮箱注册。建议使用：

```text
finance@你的域名.com
```

并绑定法人长期使用的手机号。

密码至少包含大写字母、小写字母和数字，并使用独立密码，不与企业邮箱共用。

### 第二步：选择业务类型

选择：

```text
跨境电商
```

阅读并确认协议。邀请码不是必须，不要因为陌生人承诺低费率而交出账号控制权。

### 第三步：选择公司电商账号

实名认证时选择：

```text
公司电商账号
```

不要选择个人电商账号。

### 第四步：填写企业信息

按营业执照填写：

1. 公司中文全称。
2. 统一社会信用代码。
3. 注册地址。
4. 实际经营地址。
5. 公司英文地址。
6. 经营行业。
7. 预计提款国家或地区。

没有实际店铺时，不要伪造店铺链接、销售额或订单。页面如果要求现有店铺证明，应按真实状态填写或联系官方客服确认。

### 第五步：填写法人和股东信息

1. 上传法人证件。
2. 填写法人英文姓名。
3. 填写持股超过 25% 的股东资料。
4. 完成支付宝、刷脸或页面提供的身份核验方式。

### 第六步：提交审核

提交后关注：

- 万里汇站内通知。
- `finance@` 邮箱。
- 法人手机短信。

如果状态为“待修改”，只修改系统明确指出的字段，不要反复新注册账号。

## 5. 绑定提款账户

认证通过后，优先绑定：

```text
公司同名对公银行账户
```

核对：

- 开户名称与营业执照公司名称一致。
- 银行账号正确。
- 开户行名称正确。
- 提款币种和到账币种正确。

万里汇部分规则可能允许提款到法人个人账户，但你当前应优先使用公司对公账户，以便平台收入、换汇和人民币到账能够形成清晰账务链路。

## 6. 申请平台收款账户

进入万里汇后台：

```text
申请收款账户
-> 选择电商平台
-> 选择站点或币种
-> 设置内部店铺名称
-> 提交申请
```

申请后可在店铺管理查看收款账户详情；平台要求账户证明信时，可以从万里汇开具。

账户证明信上的公司名称必须与电商平台店铺注册公司名称一致。

## 7. eBay 收款的重要限制

虽然万里汇官方列出支持 eBay 等电商平台，但 eBay 新卖家注册时可能根据注册国家和账户安排，要求绑定：

- Payoneer。
- 指定银行账户。
- eBay 页面提供的其他收款方式。

因此：

> eBay 注册页面要求什么，就先使用什么。不要为了使用万里汇而绕过 eBay 的收款验证。

正确做法：

1. 先完成万里汇企业认证。
2. 注册 eBay 时查看页面指定的收款方式。
3. 如果 eBay 明确允许绑定万里汇提供的账户，再申请并绑定。
4. 如果 eBay 强制 Payoneer，就按 eBay 流程办理 Payoneer，万里汇保留给其他平台或后续使用。

## 8. 账户安全

1. 开启双重验证。
2. 使用独立密码。
3. 法人手机由自己控制。
4. 不把验证码交给代运营。
5. 不在陌生注册链接注册。
6. 不让第三方远程控制电脑操作实名认证。
7. 定期导出交易和提款记录。
8. 每笔提款和平台结算与会计账核对。

## 9. 完成验收

- [ ] 注册的是跨境电商公司账号。
- [ ] 公司实名认证通过。
- [ ] 法人和股东信息通过。
- [ ] `finance@` 邮箱和手机号可正常接收通知。
- [ ] 同名对公账户绑定成功。
- [ ] 小额提款路径已测试。
- [ ] 能查看和导出交易记录。
- [ ] eBay 收款方式未被擅自替换。
