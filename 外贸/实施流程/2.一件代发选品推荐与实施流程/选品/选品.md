> 当前模式：1688 一件代发、先不囤货、先跑通平台成交和物流履约。  
> 判断口径：不是只看产品有没有利润，而是看“新手能不能稳定上架、能不能发货、能不能承受售后、能不能拍内容、能不能避开平台和合规风险”。

## 等级说明

| 等级 | 含义 |
|---|---|
| S | 非常适合当前阶段，可以优先买样测试 |
| A | 适合当前阶段，但要做差异化或套装 |
| B | 可以做候选，但不能当第一主线 |
| C | 有机会，但当前阶段风险或难度偏高 |
| D | 不建议当前阶段做 |

## 1. 平板支架套装

### **等级：A**

这个品类可以作为第一批重点测试品，但前提是不要只卖一个普通塑料支架。

当前看到的价格：
- 1688：约 18 元起。
- 海外平台：同类产品价格差距很大，取决于材质、承重、套装、品牌感和包邮策略。

### 为什么适合你

- eBay 可以吃搜索流量，TikTok 可以拍桌面改造内容。
- 用户愿意为“铝合金、可折叠、稳、不晃、便携”多付钱。

### 不要做什么

- 不做 9.99 美元以下的塑料支架。
- 不做没有承重、没有质感、没有差异化的普通款。
- 不做体积过大、包装薄、运输容易压变形的款。

### 最建议做的组合

不要只卖一个支架，建议做成“桌面效率套装”：

1. 铝合金可折叠平板 / 笔记本支架。
2. 便携收纳袋。
3. 理线扣 3-6 个。
4. 防滑硅胶垫。
5. 简单英文使用卡。

这样你卖的不是 18 元支架，而是“桌面办公改善方案”。

### 建议售价

- eBay 起步：19.99-29.99 美元。
- TikTok 自己发内容：24.99-34.99 美元。
- Amazon 后期：24.99-39.99 美元，但要有更好图片和评论基础。

如果真实总成本超过 15 美元，但前端只能卖 19.99 美元，就不适合一件代发。

### 1688 搜索词

- 铝合金平板支架
- 折叠笔记本支架
- 便携电脑支架
- 桌面升降支架
- 平板电脑支架一件代发

### 样品必须检查

1. 承重：放 iPad、MacBook、普通笔记本会不会下沉。
2. 铰链：开合是否松，使用时是否晃。
3. 边角：有没有割手毛刺。
4. 防滑垫：是否容易掉。
5. 重量：太重吃运费，太轻显廉价。
6. 包装：运输中会不会压弯、刮花。

### 内容怎么拍

- “桌面 10 秒变高级。”
- “脖子不再低头，平板高度直接抬起来。”
- “旅行/咖啡店办公，一折就能带走。”
- Before：电脑直接放桌上，脖子低头；After：支架抬高，桌面整齐。

### 最终判断

可以做。第一批建议买 2-3 个不同供应商的样品，对比承重、铰链、包装和重量。只要样品质感过关，这个品类比美妆和鞋服更适合你现在的一件代发阶段。

## 2. 桌面理线 / 线缆收纳套装

### **等级：A-**

这个品类适合一件代发，但必须做套装，不要卖单个小配件。

当前看到的价格：
- 1688：约 18.8 元起。
- 海外平台：套装价格可以做到 18.99-29.99 美元，但散件非常卷。

### 为什么适合你

- 痛点直观：桌面线乱、充电线掉地上、插线板难看。
- 很适合 TikTok / Reels / Shorts 的 before-after。
- eBay 搜索关键词明确，比如 cable management、cord organizer、desk cable tray。
- 成本低，但组合后客单价可以做上去。

### 最大问题

单个理线夹、扎带、线扣都太便宜，单卖没有利润。你必须做“完整解决方案”，否则会被 Temu、AliExpress、工厂卖家压死。

### 最建议做的组合

建议组合成 8-15 件套：

1. 桌下理线盒 / 插线板收纳盒。
2. 理线夹。
3. 魔术贴扎带。
4. 数据线标签。
5. 走线槽。
6. 桌边固线器。
7. 双面胶备用包。

卖点不是“几个塑料配件”，而是：

> 一套解决桌面、床头、电视柜、游戏桌、办公桌线缆混乱。

### 建议售价

- eBay：18.99-29.99 美元。
- TikTok 自己发内容：19.99-29.99 美元。
- Amazon 后期：24.99-34.99 美元。

如果只是理线夹小包，卖不到 14.99 美元以上，不建议单独做。

### 1688 搜索词

- 桌面理线器套装
- 数据线收纳夹
- 桌下理线槽
- 电线收纳盒
- 线缆管理套装
- 办公桌理线神器

### 样品必须检查

1. 胶粘力：贴桌下 24 小时会不会掉。
2. 塑料质感：是否廉价、毛边明显。
3. 套装完整度：是否真的能解决一个完整场景。
4. 适配性：粗线、细线、充电线是否都能固定。
5. 包装：小配件是否容易丢。

### 内容怎么拍

- “我的桌面线乱到崩溃，10 分钟整理完。”
- “出租屋 / 宿舍桌面改造。”
- “游戏桌理线 before-after。”
- “充电线再也不会掉到桌子下面。”

### 风险

- 胶粘类产品容易差评：粘不住、撕下来有残胶。
- 客单价不算特别高，物流和包装要控制。
- 同质化严重，图片和套装组合必须比普通卖家更清楚。

### 最终判断

可以做。这个品类适合放进第一批样品池，但要按“套装完整度”选供应商。散件不要碰。

## 3. 功能性衣架

### **等级：A-**

功能性衣架是被低估的品类，但只适合做细分功能款，不适合卖普通衣架。

### 为什么适合你

- 无尺码，不像鞋服有尺码退货。
- 不涉及电池、液体、食品，合规风险低。
- 家居收纳是长期需求，用户搜索明确。
- 可以拍小空间、衣柜改造、租房收纳内容。
- 和你现在的一件代发模式匹配，前期不需要囤货。

### 不要做什么

- 不做普通黑白塑料衣架。
- 不做太长、太重、体积大的衣架。
- 不做承重差、容易断、容易变形的款。

### 最建议做的细分方向

1. 帽子收纳挂架：棒球帽、鸭舌帽、不变形。
2. 包包挂架：小包、托特包、围巾、皮带。
3. 围巾 / 皮带衣架：多孔、多层、节省空间。
4. 多层裤架：但要注意承重和体积。
5. 内衣 / 背心 / 吊带收纳架：轻小、场景明确。

你现在看到的“衣柜内衣裙子背心多功能挂架”可以继续研究，但必须买样品看承重和体积。

### 建议售价

- 普通单件：不建议做，价格太卷。
- 2 件套 / 3 件套：16.99-24.99 美元。
- 功能更强、材质更好、承重好的套装：24.99-34.99 美元。

如果体积重导致真实总成本超过 12-15 美元，而前端只能卖 19.99 美元，利润会很紧。

### 1688 搜索词

- 帽子收纳挂架
- 包包收纳挂架
- 围巾皮带衣架
- 多功能衣柜收纳架
- 内衣背心挂架
- 多层裤架一件代发

### 样品必须检查

1. 承重：挂满后会不会弯、断、变形。
2. 体积：包装尺寸是否吃体积重。
3. 表面：有没有毛刺、刮衣服。
4. 适配：欧美衣柜、门后、衣杆是否能用。
5. 稳定性：挂多件是否倾斜。

### 内容怎么拍

- “小衣柜空间翻倍。”
- “帽子不再被压变形。”
- “包包终于不用堆地上。”
- “租房党衣柜收纳改造。”

### 最终判断

可以做，而且比美妆类更稳。优先找“轻、可折叠、承重好、可套装”的款。普通衣架不要做。

## 4. 情趣内衣

### **等级：C+**

这个品类利润高、重量轻，但平台和推广限制太强，不适合你第一阶段做。

### 为什么看起来诱人

- 产品轻，国际物流成本低。
- 很多款式均码或弹力尺码，库存压力较小。
- 毛利空间高，1688 常见拿货 15-30 元，海外售价可能高很多。
- 卫生原因导致退货率可能低于普通服装。

### 为什么当前不适合你

- Amazon、eBay、TikTok 对成人内容、露出尺度、广告素材、标题关键词都更敏感。
- TikTok 内容容易限流、下架或触发审核。
- 支付、广告、素材、年龄限制、隐私包装都要处理。
- 独立站虽然自由，但没有自然流量，新手很容易花广告费但不出单。
- 一件代发很难保证包装隐私、尺码描述、材质和实物一致。

### 如果后期要做，只能这样做

1. 不走 Amazon / eBay 主线。
2. 更适合 Shopify 独立站 + 年龄门槛 + 私域内容。
3. 素材要偏“氛围、礼物、情侣关系”，不要露骨。
4. 包装必须无痕、隐私、没有中文小票。
5. 必须买样品确认面料、弹力、气味、做工。

### 不建议做的打法

- 不要批量刷 Reddit、Tumblr、社群广告。
- 不要抓取 OnlyFans 创作者信息批量私信骚扰。
- 不要用过度露骨图片硬发 TikTok。
- 不要用平台敏感词堆标题。

这些打法短期看起来猛，长期会带来封号、投诉和支付风险。

### 建议售价

- 普通款：19.99-29.99 美元。
- 质感好、礼盒化、情侣礼物方向：29.99-49.99 美元。

但这个售价成立的前提是你有流量和信任，不是搬 1688 图就能卖。

### 样品必须检查

1. 面料是否扎皮肤。
2. 是否有异味。
3. 弹力和尺码范围是否真实。
4. 做工是否掉线。
5. 包装是否隐私。
6. 图片是否和实物差距过大。

### 最终判断

不是不能做，而是暂时不要做。这个品类适合你以后懂独立站、支付、私域内容和成人类目规则后再研究。现在不适合作为第一阶段启动品。

## 5. 假睫毛

### **等级：B-**

普通假睫毛不建议主推，但新型款、辅助工具、收纳工具可以研究。

### 为什么普通假睫毛难做

- 工厂卖家太多，价格被压得很低。
- 1688 一件代发价不一定比海外工厂卖家有优势。
- 用户对“自然度、舒适度、胶水、眼型适配”很敏感。
- 如果带胶水，过敏和合规风险更高。
- 一件代发下退货和差评处理比较麻烦。

### 可以考虑的方向

1. 假睫毛辅助夹。
2. 假睫毛收纳盒。
3. 睫毛梳 + 镊子 + 小剪刀套装。
4. 半截假睫毛 / 分段假睫毛。
5. 磁吸假睫毛，但必须买样测试吸附和舒适度。

更推荐你先做“工具套装”，不要第一阶段直接主卖普通假睫毛。

### 建议售价

- 单工具：6.99-9.99 美元，不建议主推。
- 工具套装：12.99-19.99 美元。
- 假睫毛 + 工具 + 收纳盒：19.99-29.99 美元。

如果只能卖 9.99 美元以下，利润会被物流和平台费吃掉。

### 1688 搜索词

- 假睫毛辅助器
- 假睫毛镊子
- 睫毛收纳盒
- 分段假睫毛
- 半截假睫毛
- 磁吸假睫毛
- 睫毛工具套装

### 样品必须检查

1. 戴上是否自然。
2. 梗是否扎眼。
3. 是否容易脱落。
4. 工具夹是否好用。
5. 收纳盒是否干净、有质感。
6. 是否有胶水，如果有，必须谨慎处理成分和过敏风险。

### 内容怎么拍

- “新手贴假睫毛总失败？先用这个工具。”
- “半截睫毛比整条更自然。”
- “假睫毛收纳，不再乱丢。”
- “10 秒定位睫毛，不戳眼皮。”

### 风险

- 普通款太卷。
- 胶水过敏风险高。
- 用户主观审美差异大，容易说不自然。
- 眼部产品要注意平台审核和成分说明。

### 最终判断

可以作为候选，但不要主推普通假睫毛。建议先做“假睫毛工具 / 收纳套装”，比直接卖睫毛更稳。

## 6. 穿戴甲

### **等级：C**

成品穿戴甲不适合你当前阶段，但穿戴甲周边配件可以继续研究。

### 为什么成品穿戴甲难做

- SKU 复杂：甲型、尺寸、颜色、图案、长度组合非常多。
- 审美要求高，爆款变化快。
- 普通通货太多，价格被压低。
- 真正好看的款经常断货。
- 用户收到后可能觉得“图案不精致、颜色不一样、尺寸不合适”。
- 一件代发很难稳定供应同一款。

### 可以考虑的方向

不做成品甲，做配件：

1. 穿戴甲胶贴补充装。
2. 甲片收纳盒。
3. 小锉条。
4. 木棒。
5. 甲片卸除工具。
6. 穿戴甲工具包。

这些更轻、更通用、不依赖审美，售后也比成品甲低。

### 建议售价

- 单个胶贴包：不建议主推，客单太低。
- 工具包：9.99-16.99 美元。
- 多件套 / 补充装组合：14.99-24.99 美元。

### 1688 搜索词

- 穿戴甲胶贴
- 穿戴甲工具包
- 甲片收纳盒
- 美甲锉条
- 穿戴甲卸除工具

### 样品必须检查

1. 胶贴粘性是否够。
2. 是否容易伤甲。
3. 收纳盒是否有毛边。
4. 工具是否廉价。
5. 包装是否干净。

### 内容怎么拍

- “穿戴甲总掉？可能是胶贴没选对。”
- “10 分钟在家换甲。”
- “穿戴甲工具包，新手不用乱买。”
- “甲片收纳，旅行也能带。”

### 最终判断

成品穿戴甲暂时不做。配件可以作为 B 级候选，但不能押太重。你没有工厂和审美团队时，不要和专业美甲供应链硬打。
